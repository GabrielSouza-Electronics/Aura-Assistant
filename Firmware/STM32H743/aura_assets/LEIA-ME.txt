Pacote completo desta versão. Nada aqui depende de arquivos anteriores.

    assets_rotacionados/   193 PNGs, já girados 90° à esquerda
    code/                  5 arquivos C++
    gen/                   geradores Python e o instalador

O QUE TEM NESTA VERSÃO
----------------------
Tema de circuito: o fundo é uma placa e as partículas são pulsos que correm
pelos traços. Ao aproximar a mão elas convergem e formam a esfera; o
carrossel de 5 opções gira em volta.

Quase tudo é widget nativo do Designer — fundo, logo, ícones, textos,
divisor, status, borda — então você posiciona e edita visualmente. Só as
partículas ficam em código, porque são 150 objetos por frame.


=========================================================================
PASSO 1 — INSTALAR OS ASSETS
=========================================================================

Copie a pasta inteira para o projeto. Dois lugares funcionam; o comando
muda conforme onde voce puser.

  A) Ao lado do TouchGFX (recomendado)
        Firmware/STM32H743/aura_assets/
        cd Firmware/STM32H743/aura_assets
        python gen/instalar_circuito.py ../TouchGFX

  B) Dentro do TouchGFX
        Firmware/STM32H743/TouchGFX/aura_assets/
        cd Firmware/STM32H743/TouchGFX/aura_assets
        python gen/instalar_circuito.py ..

O argumento e sempre a RAIZ do projeto TouchGFX — a pasta que contem
assets/, gui/ e o application.config. Se errar, o script para e diz o
caminho que resolveu, em vez de instalar nada e falhar no fim.

Prefiro (A): o Designer varre assets/ e gui/, e o build percorre gui/src/
recursivamente. Manter os geradores fora do projeto evita que PNGs de
origem sejam importados por engano.

O instalador APAGA assets/images/aura/ antes de copiar. É proposital:
sobras de temas antigos geram IDs a mais e quebram as sequências numeradas
que o código percorre com aritmética.

Ele também escreve o application.config com:
    format          L8_ARGB8888
    compression     none
    rotate90        true        <- o Layout Rotation de cada imagem
    section         ExtFlashSection

Abra o Designer e clique Generate Code.

CONFIRA na aba Images que a coluna Layout Rotation mostra 90 em todas as 193.
Se vier vazia, a chave do config tem outro nome na sua versão: abra o
application.config, veja como uma imagem que você já configurou à mão
aparece, e ajuste a string 'rotate90' no topo do instalar_circuito.py.


=========================================================================
PASSO 2 — CONFIGURAR O DISPLAY
=========================================================================

Config → Display:
    Dimensions           480 × 480
    Display Orientation  PORTRAIT
    Color Depth          16 bit

Três peças trabalham juntas na rotação:
    1. Display Orientation = Portrait
    2. Layout Rotation = 90 em cada imagem
    3. Os PNGs já saem girados do gen_rotate.py

No Designer e no simulador tudo aparece deitado. Está certo — o simulador
desenha o framebuffer como ele está na memória. É o painel físico, montado
girado, que devolve a orientação correta.

=========================================================================
PASSO 5 — LIGAR NA VIEW
=========================================================================

Veja code/InitialView_REFERENCIA.txt. Em resumo, no InitialView.hpp:

    #include <gui/common/CircuitField.hpp>
    #include <gui/common/MenuLogic.hpp>

    CircuitField field;
    MenuLogic    menu;

No setupScreen(), depois do que o Designer gerou:

    field.setPosition(0, 0, 480, 480);
    insert(&board, field);      // entra logo depois do fundo da placa

insert() coloca o widget numa posição específica da pilha em vez do fim.
Assim as partículas ficam sobre a placa e sob todo o resto, sem você
precisar reordenar nada no Designer.


=========================================================================
O QUE VOCÊ PODE MUDAR NO DESIGNER SEM TOCAR NO CÓDIGO
=========================================================================
  - posição e tamanho de qualquer widget
  - trocar a imagem de um ícone
  - alpha de qualquer elemento
  - cor do Box de fundo e do preenchimento da bateria
  - velocidade das AnimatedImage
  - adicionar widgets novos

O que NÃO mexer:
  - os nomes dos widgets
  - a ordem icon0..icon4 (o código os indexa por posição)


=========================================================================
ARMADILHAS JÁ DESCOBERTAS
=========================================================================
1. near, far e CY são macros do Windows (windef.h) e o MinGW do simulador
   as arrasta via HAL.hpp. Identificadores curtos assim colidem, e o erro
   aparece SÓ no simulador.

2. TextureMapper depende de features opcionais do framework. Com L8
   desabilitado ele não desenha nada, sem erro nem aviso. Por isso nenhum
   widget aqui o usa.

3. TextArea não acompanha o Layout Rotation das imagens — apareceria na
   vertical. Todos os textos aqui são sprites.

4. Sprites precisam de alpha 0 nas bordas, senão a moldura inteira fica
   levemente opaca e aparece como caixa sobre o fundo escuro.

5. L8_ARGB8888 tem paleta de 256 cores. Misturar duas rampas livremente
   estoura; derive tudo de um escalar quantizado.

6. IDs de bitmap precisam ser consecutivos onde o código faz
   BITMAP_X_00_ID + i. Cada sequência tem pasta própria por isso.

7. Asset novo precisa passar pelo gen_rotate.py antes de instalar. Um PNG
   não girado no meio dos girados fica de lado, e só aparece no display.


=========================================================================
REGERAR OS ASSETS
=========================================================================
    cd aura_assets
    python gen/gen_circuit.py     # placa, pulsos, partículas com anel
    python gen/gen_icons.py       # ícones, anel de progresso, setas
    python gen/gen_text.py        # rótulos e mensagens
    python gen/gen_logo.py        # logo da barra + arco
    python gen/gen_hero.py        # logo grande da tela de espera
    python gen/gen_status.py      # wifi e bateria
    python gen/gen_rotate.py      # gira TUDO 90° à esquerda
    python gen/instalar_circuito.py ../TouchGFX

gen_rotate.py --check imprime a tabela de coordenadas transformadas.


=========================================================================
MENU SETTINGS
=========================================================================
    python gen/gen_settings.py            # gera sprites + preview
    python gen/gen_settings.py --install  # copia para assets/images/aura/
                                          # settings e reescreve
                                          # gui/include/gui/common/SettingsLayout.hpp

A fonte Poppins fica em aura_assets/fonts/ (OFL); o gen_text.py procura
ali antes do caminho Linux antigo.

As imagens de aura/settings (13) e aura/glyphs (54) sao geradas JA
GIRADAS - nao passam pelo gen_rotate.py. No Designer, aba Images, ajuste
como as demais: Layout Rotation 90, formato L8_ARGB8888, dither nenhum.
Depois Generate Code.

Os VALORES (Wi-Fi, Bluetooth, Brightness) sao texto livre, desenhados com
o atlas aura/glyphs pelo widget GlyphText (TextArea nao gira). Para mudar
em tempo de execucao, de qualquer task:
    APP_UISettings_SetText(APP_UI_SETTING_WIFI, "HomeNet");
A linha Sound mostra o volume do BSP (0..10) como "N/10".
Texto sai em maiusculas; caractere fora do atlas vira '?'; texto longo
demais para a linha e cortado com "..".

Os widgets (caixas, valores, halo, subtitulo) sao criados em codigo no
Screen1View; a animacao e o foco estao em SettingsLogic.

NAVEGACAO (SettingsLogic) - mesmas regras e constantes do carrossel
(TouchGFX/gui/include/gui/common/HandInput.hpp). A posicao da mao em
relacao ao centro do sensor e um joystick:
    Lista:   mao para cima/baixo -> a lista anda para cima/baixo, com
             velocidade proporcional; mao no centro para e alinha
             mao na direita      -> entra na linha (ajuste)
             mao na esquerda     -> volta ao carrossel
    Ajuste:  mao para cima/baixo -> +1 / -1 (Wi-Fi/Bluetooth: liga/desliga)
             mao na esquerda     -> volta para a lista
Direita/esquerda disparam como o "voltar" do carrossel (alem de 0.55 por
200 ms) e so rearmam com a mao de volta perto do centro.
